# 中文图形验收

日期：2026-11-09。使用同一分支真实 Vite 前端和本次任务生成的本地 Convex/SQLite 世界，12位 NPC，Mock 对话，无真实模型 Key、无付费 API。

## 实际看到和操作过的内容

- 桌面 Chromium：像素地图、移动角色、中文标题和帮助、皮特的人物介绍、角色智能折叠面板、预算/语言等控件可见，中文没有方框缺字。
- 主界面中文→英文→中文；标题、人物译名及控件同步切换。刷新保留浏览器语言。
- 仅切界面语言后，NPC语言仍显示原值；再使用独立NPC语言控件切英文，页面显示实际保存成功，随后恢复简体中文。已有中文聊天保持原文。
- 388 CSS像素窄视口：页面宽度和scrollWidth均为388，无页面横向溢出；NPC语言控件及说明换行可读。中文聊天气泡实测多行显示，姓名和时间未被裁掉。
- 帮助弹窗可滚动，通过“关闭”和Escape重复关闭后回到原页面，没有残留遮罩。
- 暂停/继续、加入/离开小镇成功。邀请NPC后看到“正在走近”，中途离开正常恢复“加入小镇”；没有把走近过程冒充已完成真人聊天。
- 地图编辑器：图块集加载和画布绘制成功；画一个测试图块后切英文，画布内容保留，再恢复中文。
- 编辑器通过浏览器返回入口，再进入精灵编辑器，中文控件、精灵图块集和网格正常显示。

## 本轮发现并修复

1. 无WebGL时Pixi整页白屏。使用官方同版本 `pixi.js-legacy@7.2.4` 注册Canvas回退，游戏和两个编辑器都已实际渲染，不修改浏览器安全设置。
2. 动作控件使用没有href的a元素，不具备正常键盘按钮语义。改为button，真正导航仍保留链接；加入2项React静态渲染回归测试。
3. 底部控制组窄屏不换行、游戏网格最小宽度不明确。添加换行及minmax/min-width限制；NPC面板小屏允许换行。
4. 编辑器缓存读取不存在的配置导出，循环不执行。改按实际加载图片尺寸分别生成16/32像素图块，重载时清空旧缓存。
5. 补充标准动态错误码、默认真人文案；原始自由文本不再被当枚举修改下划线/大小写，明确标注未自动翻译。
