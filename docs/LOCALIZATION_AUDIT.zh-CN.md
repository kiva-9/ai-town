# 中文覆盖审计

## 统计口径与快照

以下是静态翻译字段数，不是全文、页面数，也不是动态对话的覆盖率。汉字计数使用 Unicode
U+3400–U+9FFF；标点、数字、英文字母不计。通过 TypeScript
AST 读取对象/数组，排除注释和源码中的重复引用。

提交 `aeb49d2c4080b740cad84de1fbb111d73cb4e2be` 的只读审计快照：

- `src/i18n.ts`：227 个中文词条，1429 个汉字。
- `src/editor/i18n.js`：26 个中文词条，202 个汉字。
- `data/characters.ts`：当前增强版的12位角色，各有
  `nameZh`、`identityZh`、`planZh`，共36字段、722汉字。其中姓名29字、介绍556字、目标137字。
- 合计289项、2353汉字。不含生成提示、模拟对话、文档及其他文件。

本轮补漏后的工作区增量快照：主字典239项、1522汉字，即增加12项、93汉字；编辑器和角色统计不变，合计301项、2446汉字。新增项包括输入预算错误、真人默认文案、原始记录提示、界面语言与独立 NPC 生成语言控件。后续增改应重新统计，不将此数字当作永久覆盖率。

## 已覆盖与明确边界

- 主界面的帮助、控制、角色介绍、历史列表标签、NPC 性格/状态/动作/已知事件与原因、已知错误码、编辑器控件已有静态中文。原有角色身份和协议 ID 不变。
- `convex/npc/language.ts`、`convex/agent/conversation.ts`、`convex/agent/memory.ts`
  使用语言指令引导之后的对话、摘要与反思生成中文。这不是预先翻译全部可能内容，也不能单凭提示保证模型始终输出中文。模拟对话只有3条固定模板，不可冒充真实模型中文验收。
- `src/components/Messages.tsx`
  保留历史对话原文。自定义人物介绍、任意旧记忆和承诺描述不被机器改写；NPC 面板对未命中静态字典的自由文本标注“原始记录，未自动翻译”。自由文本中的下划线、大小写、换行保持不变。
- 真人默认介绍只精确匹配
  `Me is a human player`，不替换用户扩写的介绍。原有角色介绍也只精确匹配原始资料。
- 品牌、模型名称、技术单位、协议字段和未知扩展枚举可保留英文。未知枚举不代表已翻译；新枚举须补词条。
- 本浏览器的界面语言与整个小镇的 NPC 生成语言独立。后者只允许服务器授权的控制入口修改，不追溯翻译历史。
