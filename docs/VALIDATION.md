## 未完成或不能据此推断

- **没有真实 Decisions API 冒烟测试。** 没有配置 Key、账户权限及正式单价；未发起付费调用。客户端请求/响应解析、429/超时/认证/非法结果/低置信度等通过离线测试，不等于账户已获得接口权限。
- **没有真实 LLM 中文对话、摘要和多语向量检索质量评测。** 语言提示和路径已实现，实际模型效果需配置服务后验证。Mock 使用明确标记的固定话术，并跳过向量摘要生成，保留真实模式原有机制。
- **仍未做真实手机和系统中文输入法选字验收。** 已完成桌面 Chromium 与388 CSS像素窄视口的中文图形检查、长消息气泡、帮助关闭和编辑器返回流程；窄视口采用浏览器缩放，不冒充手机设备模拟。见 [图形验收](GRAPHICAL_QA.zh-CN.md)。
- 模式切换经过引擎代数失效保护；不是靠每 30 秒自然刷新避免竞态。
- 预算是保守金额预约和请求限制，不是供应商强制的硬性账单上限；建议同时使用供应商项目预算。
- 实验采用受控合成事件/结果模型，并非原版完整世界的严格实时对照，也不能用行动次数证明自然程度提高。
- 承诺、帮助、关系修复已有数据和事件 reducer 支持，但尚不从任意自然语言对话可靠提取承诺/帮助事实。普通完成对话仅增加熟悉度，不假设“愉快”或“修复”。
- 初始关系从中性印象开始，根据真实事件发展，未预设角色故事。旧历史和自定义人物资料保留原文，不批量重写数据库。
- 仓库本身不是一个已经上线的公共游戏服务。图形验收使用仅绑定127.0.0.1的临时自托管后端，没有部署到公共云或启用真实 API。

## 环境说明

自动本地部署 CLI 在该沙箱的端口探测环节循环并耗尽 Node 堆。使用官方后端显式端口可启动。最初不必要的 Node action 声明会要求沙箱不允许的 Unix socket，现已改成标准 Convex action 运行时并通过部署，不需要解除限制。

最初的命令执行会话隔离 localhost；后续在同一桌面会话启动本地后端与前端后，浏览器验收可行。这些验证环境限制不应被误报为项目本身无法运行。没有启用付费云服务，没有上传本地密钥或数据库。
